# Z1 – Moja online vizitka (WEBTE1, ZS 2026/2027)

**Meno:** Gabriel Kováč, **krúžok:** 5
**Odkaz na stránku (školský server):** https://doplnit-adresu-skolskeho-servera

## O webe
Osobná vizitka o piatich podstránkach: profil, životopis, pracovné prostredie (interaktívna fotka stola s hotspotmi), rozvrh (zvýraznenie práve prebiehajúcej hodiny, filter, priebeh semestra) a interaktívna mapa (škola a bydlisko, vlastné body, vzdialenosť podľa Haversinovho vzorca, ukladanie do localStorage). Použité sú iba HTML5, CSS a JavaScript, mapová knižnica Leaflet je len na stránke `map.html`.
